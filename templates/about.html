About SmartBus AI

A college project that predicts when a bus will reach your stop. It compares a Machine Learning baseline with a GRU (Gated Recurrent Unit) recurrent network that learns from sequences of speed, traffic and past trips.

Frontend

HTML, CSS, JavaScript, Chart.js, SVG map

Backend

Python Flask REST API

Database

SQLite: buses, routes, trips, contacts

Models

Random Forest baseline, GRU (ml/train.py)
